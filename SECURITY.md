# Security policy

Vime is no longer maintained. No version receives fixes, including security fixes, and this repository is archived.

| Version | Supported |
| ------- | --------- |
| 5.x     | No        |
| < 5     | No        |

If you rely on Vime, migrate to [Video.js 10](https://videojs.org?utm_source=vime), which is actively maintained by the teams behind Vime, Vidstack, Plyr, Media Chrome, and Video.js. Start with the installation guide for [React](https://videojs.org/docs/guides/installation/react?utm_source=vime) or [web components and other frameworks](https://videojs.org/docs/guides/installation/html?utm_source=vime).
