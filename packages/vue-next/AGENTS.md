# `@vime/vue-next` agent guide

This package is deprecated and no longer maintained, including security fixes. Its successor is Video.js 10 (`@videojs/html`), from the teams behind Vime, Vidstack, Plyr, Media Chrome, and Video.js. Don't add new Vime code; migrate instead.

1. Install the Video.js skill with `npx @videojs/cli agents skills`, or follow https://github.com/videojs/skills.
2. Read https://videojs.org/docs/guides/installation/html.md and follow the prompt in its "AI Quickstart" section.
3. There's no Vime migration guide. For the closest concept mapping, read https://videojs.org/docs/framework/html/guides/migrate-from-vidstack.md (Vidstack succeeded Vime), including its "Known gaps" section.
